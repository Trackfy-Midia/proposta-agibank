Jornada do portal
captivo Wi-Fi

Este documento descreve o fluxo completo que o usuário percorre desde a conexão ao Wi-Fi até o acesso liberado, especificando o que cada parte (Linktel, Trackfy e V4 Company) executa em cada passo. Use o simulador ao lado para navegar entre as telas.

01
Detecção e redirect
Linktel

O usuário conecta ao Wi-Fi "Agibank Barra Funda". A Linktel detecta o dispositivo sem sessão ativa e intercepta as requisições HTTP/HTTPS, redirecionando o browser para a URL do portal captivo Trackfy.

A validar com Linktel
  • URL do portal captivo Trackfy que deve ser configurada na Linktel
  • Parâmetros enviados no redirect: MAC address do dispositivo, session token, IP do cliente
  • Comportamento para HTTPS (intercept via certificate ou só HTTP redirect?)
02
Splash screen Agibank
Trackfy

Portal exibe a splash com identidade visual 100% Agibank: logo, cor, mensagem "Seu Wi-Fi é uma cortesia Agibank" e botão "Conectar agora". Nenhum dado é coletado ainda.

✓ Nenhuma URL externa nesta tela. Nenhuma whitelist necessária por parte da Linktel.
03
Formulário de qualificação
Trackfy

Captura os dados do lead com identidade visual Agibank. Campos obrigatórios: nome completo, telefone, data de nascimento. Campos de qualificação: perfil empregatício (CLT / Pensionista / Autônomo / Outro) e interesse em empréstimo pessoal (Sim / Não).

✓ Nenhuma URL externa nesta tela. Nenhuma whitelist necessária.
04
Criativo pós-cadastro
Trackfy Agibank

Ao clicar "Concluir cadastro", o lead é enviado via webhook para a V4 Company. O portal exibe um criativo dinâmico baseado no perfil respondido:

Path A · CLT + Interesse = Sim

Criativo "Crédito Pessoal Agibank". CTA abre o WhatsApp Agibank (interação passiva — usuário inicia a conversa).

Path B · Demais perfis

Criativo "Abrir Conta Agibank". CTA direciona para download do app com link parametrizado. V4 Company dispara WPP ativo.

✓ Os CTAs desta tela (WhatsApp e App Store) são acessados após a conclusão do cadastro — Wi-Fi já liberado neste momento. Nenhuma whitelist necessária.
05
Liberação de acesso Wi-Fi
Linktel

Ao concluir o cadastro, o acesso à internet é liberado automaticamente para qualquer site. O usuário vê a tela de confirmação "Acesso liberado!" enquanto já pode navegar livremente.

A validar com Linktel
  • Mecanismo exato de liberação: Trackfy chama endpoint Linktel? Redirect para success_url com token? Outro?
  • Timeout de sessão: por quanto tempo o acesso fica ativo após o cadastro?
  • Comportamento em caso de falha no envio do formulário Trackfy
  • Re-autenticação: se o usuário desconectar e reconectar, precisa refazer o cadastro?
06
Ativação via WhatsApp
V4 Company Agibank WPP

Apenas para Path B (não-CLT, ou CLT sem interesse em crédito). Após receber o lead via webhook, a V4 Company dispara uma mensagem ativa pelo número verificado Agibank no WhatsApp Business, no celular cadastrado no Passo 03.

ℹ Não envolve Linktel. Executado inteiramente por V4 Company via API do WhatsApp Business.
